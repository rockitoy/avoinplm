Install into a **new, empty test database** only: the post-install hook changes company
settings (variants, work orders, units, taxes included in sale prices, webshop prices,
the MTO route) and creates BoMs, stock and reordering rules.

Requirements: the AvoinPLM modules (this repository), the configurator modules of
[odoo-konfiguraattori](https://github.com/rockitoy/odoo-konfiguraattori) and OmniaGit
odooplm (branch `20.0`) in the addons path.

1. Create the database with country Finland and currency EUR (the module does not load the
   Finnish chart of accounts or change the currency itself).
2. `odoo-bin -d <db> -i rockit_bike_demo` (pulls in AvoinPLM, the configurator modules and
   the bridge module).
3. Follow [DEMO.md](https://github.com/rockitoy/avoinplm/blob/20.0/rockit_bike_demo/DEMO.md).

The XML data in `data/` is generated by `tools/generate_data.py`. The hook steps can be
run again; each step checks whether it is already done. The `migrations/` scripts only
upgrade earlier versions of the demo database.
