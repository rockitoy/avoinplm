User rights (no inventory, purchase or website administrator rights needed):

- Create a revision: *OdooPLM - Integration User* + *Products: Create*.
- Release a revision: additionally *OdooPLM - PLM / Release Users*.
- Apply *Open orders* changes to MOs and RFQs: Manufacturing / Purchase user rights,
  because these change production and purchase documents.

Phase-in replenishment works with standard reordering rules; the column *Superseded
revision stock* on the replenishment view shows the old-revision stock that is counted.
