Nothing to configure. Put both repositories in the addons path (`avoinplm` and
`odoo-konfiguraattori`); the module is installed automatically when
*rockit_plm_floating_revision*, *rockit_mrp_bom_component_family* and
*rockit_bom_attribute_match_dynamic* are installed. In an existing database where they
already are, install it explicitly: `-i rockit_plm_component_family_bridge`.
