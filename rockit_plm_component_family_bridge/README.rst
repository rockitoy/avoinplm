**Status: Beta** – tested in a demo environment, not yet in customer
production.

Glue module between AvoinPLM (*rockit_plm_floating_revision*) and the
configurator modules of
`odoo-konfiguraattori <https://github.com/rockitoy/odoo-konfiguraattori>`__
(*mrp_bom_attribute_match*, *rockit_bom_attribute_match_dynamic*,
*rockit_mrp_bom_component_family*). Installed automatically when both
sides are installed.

- **Attribute-matched lines** (*Component (product template)*) and
  **component families** use the PLM revision that is released and
  effective at use time, and use up superseded revisions first, like
  fixed lines do.
- Fixed floating lines in BoMs that *mrp_bom_attribute_match*
  virtualises (BoM cost, BoM structure report) are resolved to the
  effective revision.
- The *Revision* column shows ``↻ <rev>`` for attribute-matched lines
  and ``↻`` for lines with component families (the item is chosen per
  produced variant).

Without this module *rockit_plm_floating_revision* works on fixed BoM
lines only.

Usage
=====

Nothing to configure. Put both repositories in the addons path
(``avoinplm`` and ``odoo-konfiguraattori``); the module is installed
automatically when *rockit_plm_floating_revision*,
*rockit_mrp_bom_component_family* and
*rockit_bom_attribute_match_dynamic* are installed. In an existing
database where they already are, install it explicitly:
``-i rockit_plm_component_family_bridge``.
