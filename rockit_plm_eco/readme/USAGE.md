1. Approve the change request (odooplm activity, *ECO* button) → ECO is created.
2. On the ECO add affected items and BoM versions, choose the effectivity, *Analyse impact*.
3. *Create revisions*: new revisions (with variants, codes, vendors, documents, BoMs) and
   draft BoM versions. Edit them.
4. Confirm and release each revision in PLM. The last release closes the ECO.
5. *Open orders* proposes moving unstarted MOs and RFQs to the new revision.
