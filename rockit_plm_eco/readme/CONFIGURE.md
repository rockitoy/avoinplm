- Users: *OdooPLM - Integration User* (create and edit ECOs; Manufacturing users can
  read them), *Activity User* (odooplm activity_validation) for the change request (ECR)
  steps, *OdooPLM - PLM / Release Users* to release revisions, *Products: Create* to
  create revisions.
- ECO numbers come from the sequence *Engineering change order* (`ECO-0001`).
- The scheduled action *PLM: activate BoM versions of ECOs effective today* (hourly)
  activates BoM versions of ECOs with date effectivity.
